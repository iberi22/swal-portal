# Security Policy

## Supported Versions

| Version | Supported |
| --- | --- |
| Latest Release (`main`) | ✅ Yes |
| Older Versions | ❌ No |

## Reporting a Vulnerability

Please report vulnerabilities privately via GitHub Security Advisories ("Report a vulnerability" on this repo).

**Do not open public issues for security reports.**

## Response Targets

- **Acknowledgment:** Within 5 business days.
- **Status Update:** Within 14 days.

We follow coordinated disclosure.
Note: There is currently no bug bounty program.
