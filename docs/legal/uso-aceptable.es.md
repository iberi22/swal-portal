# Política de uso aceptable de Xavier Cloud

**Versión:** borrador 0.1 · **Fecha:** [FECHA DE PUBLICACIÓN]

Xavier Cloud existe para respaldar, sincronizar y consultar la memoria de tus agentes. Esta política protege a todos los clientes y a la infraestructura compartida. Forma parte de los [Términos de servicio](terminos-de-servicio.es.md).

## No está permitido

1. **Contenido ilegal:** almacenar o distribuir material de abuso sexual infantil, contenido que infrinja derechos de autor o marcas, datos obtenidos ilegalmente o cualquier contenido prohibido por la ley colombiana o la de tu país.
2. **Datos personales de terceros sin base legal:** subir datos personales de otras personas sin autorización o sin otra base legal válida, o datos sensibles sin las garantías que exige la ley.
3. **Software malicioso:** almacenar, distribuir o ejecutar malware, ransomware o herramientas para comprometer sistemas ajenos.
4. **Ataques y abuso de red:** escanear, sondear o atacar el Servicio u otros sistemas; intentar acceder a cuentas o datos de otros clientes; eludir la autenticación.
5. **Evadir límites:** crear varias cuentas, compartir claves de API o manipular el cliente para saltarte los límites de almacenamiento, equipos o IA de tu plan.
6. **Reventa no autorizada:** revender o sublicenciar el Servicio, o usarlo como almacenamiento genérico para terceros, sin un acuerdo escrito (plan Empresa).
7. **Uso no relacionado:** usar el almacenamiento como hosting de archivos públicos, CDN, minería de criptomonedas o para cargas que no sean memoria y respaldos de Xavier.
8. **Abuso de la IA en la nube:** usarla para generar contenido ilegal, spam masivo o para intentar extraer modelos o datos de otros clientes.
9. **Suplantación:** hacerte pasar por SWAL, por otro cliente o por terceros.

## Uso razonable

Los límites de cada plan figuran en la página de precios. Si tu uso pone en riesgo la estabilidad del Servicio, podemos limitarlo temporalmente y te contactaremos para buscar el plan adecuado.

## Qué hacemos si se incumple

Según la gravedad: aviso, limitación temporal, suspensión o cierre de la cuenta. Salvo riesgo inminente u orden de autoridad, te avisaremos antes y te daremos oportunidad de exportar tu Contenido. Podemos reportar a las autoridades el contenido manifiestamente ilegal.

Como el Contenido se guarda cifrado y **no lo revisamos de forma rutinaria**, actuamos principalmente ante denuncias, señales técnicas de abuso (por ejemplo, picos anómalos de uso) o requerimientos de autoridad.

## Reportar abuso o vulnerabilidades

Escribe a [CORREO DE ABUSO / SEGURIDAD] con la mayor información posible. Si encuentras una vulnerabilidad, repórtala de forma responsable y no accedas a datos de otros clientes; no emprenderemos acciones contra investigaciones de buena fe.
