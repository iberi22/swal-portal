## 7. Top 5 fixes

* Command: `echo "Manual analysis based on previous commands"`
* Output: `Manual analysis based on previous commands`

1. **Missing test/lint scripts and CI validation**
   * Problem: `deploy.yml` pushes directly to Pages on main without verifying the codebase, and no test/lint scripts exist.
   * Evidence: `pnpm run test` fails, `.github/workflows/deploy.yml` has no verification jobs.
   * Proposed change: Add `test`, `lint`, and `typecheck` scripts to `package.json` and add a CI job to run them before deploy.
   * Effort: M
   * Verification command: `pnpm run test && pnpm run lint`

2. **Remove confidential internal enterprise project descriptions**
   * Problem: `ecosystem.ts` and `TimelineSection.svelte` expose details about a private/confidential internal intelligence platform (SECOP II).
   * Evidence: `src/data/ecosystem.ts` (Private internal intelligence platform...), `src/components/TimelineSection.svelte` (Forensic SECOP II...).
   * Proposed change: Remove or obfuscate references to confidential internal projects from the public repository.
   * Effort: S
   * Verification command: `grep -i "confidential" src/data/ecosystem.ts src/components/TimelineSection.svelte || true`

3. **Resolve vulnerabilities in dependencies**
   * Problem: `pnpm audit` reports 22 vulnerabilities (10 high).
   * Evidence: `pnpm audit` output (`Severity: 4 low | 8 moderate | 10 high`).
   * Proposed change: Update vulnerable dependencies using `pnpm update` or apply specific overrides in `package.json`.
   * Effort: M
   * Verification command: `pnpm audit`

4. **Update README to reflect actual Astro version**
   * Problem: README states Astro 6, but package.json has Astro 7.
   * Evidence: `README.md` lines 14, 19 vs `package.json` line 16.
   * Proposed change: Update `README.md` to reference Astro 7 instead of Astro 6.
   * Effort: S
   * Verification command: `cat README.md | grep "Astro 7"`

5. **Self-host Google Fonts for strict local-first compliance**
   * Problem: The portal relies on remote Google Fonts, breaking strict offline-first functionality.
   * Evidence: `src/layouts/Layout.astro` fetches fonts from `fonts.googleapis.com`.
   * Proposed change: Download the fonts and serve them locally from `public/fonts`.
   * Effort: S
   * Verification command: `grep -r "fonts.googleapis.com" src/ || true`
